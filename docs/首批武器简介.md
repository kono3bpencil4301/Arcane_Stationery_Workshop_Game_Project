# 首批武器简介

## 1. 铅笔

**类别：** 记录类
**定位：** 稳定远程输出 / 精准穿透 / 后排点杀

铅笔是一把基础且可靠的远程武器，会朝瞄准方向发射笔芯，对直线上的敌人造成穿刺伤害。它拥有稳定的射程、命中精度与穿透能力，适合快速处理飞行单位、固定远程敌人以及藏在敌群后方的高威胁目标。

铅笔的绘制技能允许玩家画出一条细长笔迹，笔迹实体化后会沿路径对敌人造成连续伤害，并可通过直线度、长度或终点位置触发额外效果。

### 核心特点

- 攻击稳定，使用门槛较低
- 擅长远距离精准打击
- 能够穿透排成直线的敌人
- 适合优先击杀远程、飞行和脆弱后排单位
- 面对大量包围、高速贴身和弹幕反射敌人时效率较低

### 一句话定位

> **铅笔是一把精准稳定的直线穿透武器，擅长从敌群中快速删除最危险的目标。**

------

## 2. 粉笔

**类别：** 记录类
**定位：** 条件爆破 / 阵型惩罚 / 群体清理

粉笔是一把中远距离直线爆破武器。粉笔头第一次命中敌人时会造成伤害并穿透目标，同时进入裂纹状态；随后命中第二名敌人或墙壁时发生炸裂，对周围目标造成范围伤害，并留下短暂的粉笔灰区域。

粉笔尤其擅长处理排成一列、聚集追击或围绕召唤者行动的敌群。玩家需要观察敌人的站位，利用第一名敌人作为引信，再让粉笔撞击后方目标完成爆炸。

粉笔的绘制技能可以在地面画出粉笔线。敌人跨过粉笔线后会获得板书标记，下一发粉笔命中被标记目标时可以直接爆炸。

### 核心特点

- 第一次命中穿透，第二次命中爆炸
- 爆炸后留下粉笔灰区域
- 擅长攻击密集、成列和召唤型敌群
- 对敌人站位和攻击角度有一定要求
- 面对分散飞行、高速横移和孤立目标时效率较低

### 一句话定位

> **粉笔是一把利用敌人阵型触发二段爆炸的远程武器，第一名敌人是引信，第二名敌人是撞针。**

------

## 3. 橡皮擦

**类别：** 辅助类
**定位：** 常驻防御 / 污染清理 / 近距离反制

橡皮擦是一把半常驻型辅助武器。只要装备在武器槽中，三块橡皮就会以 120 度间隔持续围绕角色公转。即使当前正在使用其他武器，三块公转橡皮依然会擦除接触到的轻型敌方弹幕、地面污渍与污染区域，并将靠近的敌人击退，但不会对敌人造成伤害。

当玩家主动切换并持有橡皮擦时，三块公转橡皮会在保留擦除与击退能力的同时获得接触伤害。主动持有橡皮擦意味着玩家暂时放弃远程主武器输出，换取能够直接伤害贴身敌人的近距离反制能力。

按住鼠标右键后，玩家会唤出一块小型魔法橡皮。小橡皮会在有限范围内实时跟随鼠标移动，擦除经过路径上的污染、弹幕和异常效果，并对接触到的敌人造成较高伤害。

### 核心特点

- 装备后三块橡皮以 120 度间隔持续围绕角色公转
- 未主动持有时不会造成伤害，但仍能擦除污染和弹幕
- 无论是否主动持有都能击退靠近的敌人
- 只有主动持有时，公转橡皮才能造成接触伤害
- 技能小橡皮会跟随鼠标实时移动
- 擅长处理污渍、粉尘、孢子和地面污染
- 面对飞行单位、远程激光与硬质装甲时效率较低

### 一句话定位

> **橡皮擦是一把用三块公转橡皮常驻清理弹幕与污染、持续击退近身敌人的辅助武器，只有主动持有时才会将公转接触转化为伤害。**

# 三把武器对比

| 武器   | 主要职责           | 擅长目标                       | 主要弱点                     | 操作重点     |
| ------ | ------------------ | ------------------------------ | ---------------------------- | ------------ |
| 铅笔   | 精准输出、直线穿透 | 飞行单位、远程敌人、脆弱后排   | 包围敌群、反弹护甲、高速贴身 | 瞄准危险目标 |
| 粉笔   | 二段爆破、群体清理 | 密集敌群、召唤物、直线追击敌人 | 分散单位、孤立目标、高速横移 | 观察敌人阵型 |
| 橡皮擦 | 防御反制、污染清理 | 地面污渍、弹幕、贴身杂兵       | 飞行单位、激光、硬质装甲     | 控制擦除路径 |

# 三武器组合关系

三把武器共同构成一套完整的基础战斗循环：

```text
铅笔处理远程与高威胁目标
→ 粉笔清理密集敌群
→ 橡皮擦清除弹幕与战场污染
→ 根据敌人行为不断切换武器
```

其中粉笔与橡皮擦可以形成特殊联动：

```text
粉笔爆炸留下粉笔灰
→ 切换橡皮擦
→ 擦除粉笔灰
→ 触发额外冲击波或粉尘爆发
```

这使三把武器分别对应三种战场阅读方式：

- **铅笔读取目标**
- **粉笔读取阵型**
- **橡皮擦读取环境**
