# 《魔法文具工坊》首批敌人图鉴与武器克制关系

## 一、设计总览

本作中的敌人来源于文具、材料与工坊环境中的损耗、老化、污染和异常状态。

敌人与武器之间不采用简单的属性相克，而是通过以下机制产生克制关系：

- 铅笔擅长精准点杀、远程目标、飞行单位和暴露弱点。
- 粉笔擅长密集敌群、直线阵型、召唤单位和狭窄通道。
- 橡皮擦擅长地面污染、轻型弹幕、异常区域和贴身杂兵。
- 敌人可以通过装甲反弹、快速横移、飞行、视野遮挡、污染地形等方式反制特定武器。

本版本共包含：

| 敌人等级 | 数量 |
| -------- | ---- |
| 普通敌人 | 15   |
| 精英敌人 | 5    |
| 合计     | 20   |

# 二、纸张系敌人

## 1. 墨晕团

**类别：** 纸张系 / 墨迹污染
**定位：** 地面污染 / 缓慢包围
**常见生态：** 记录地板、载体地板
**威胁等级：** 低至中

### 损耗来源

墨晕团来源于纸张受潮后墨水发生洇染、扩散和模糊的现象。文字原本清晰的边界逐渐消失，最终在亚空间中形成具有自主意识的流动墨斑。

### 外观表现

它是一团低矮的黑蓝色软体生物，身体边缘不断向外渗出细小墨丝。移动时地面会留下不规则的潮湿印迹，身体中央偶尔浮现被墨水覆盖的残缺文字。

### 行为与攻击

墨晕团会缓慢接近玩家，并主动寻找其他墨晕团形成包围。

它经过的区域会留下“墨晕污渍”：

- 玩家踩中后移动速度降低。
- 闪避距离缩短。
- 连续停留会积累浸染状态。
- 污渍会缓慢扩大，但拥有持续时间上限。

墨晕团本身攻击力不高，真正的威胁是逐渐压缩玩家的安全移动空间。

### 被武器克制

**橡皮擦，强克制**

主动持有橡皮擦时，可以直接擦除墨晕污渍。技能小橡皮还可以沿污染边缘移动，一次清出完整通道。

**粉笔，中强克制**

墨晕团移动缓慢且喜欢聚集，容易成为粉笔的第一、第二命中目标。爆炸可以同时清理多个墨晕团。

**铅笔，普通应对**

铅笔可以远程击杀，但直线攻击只能解决敌人本体，不能处理已经形成的墨迹污染。

### 对武器的反制

- 墨迹迫使玩家持续移动，降低铅笔稳定瞄准的时间。
- 分散的墨晕团会让粉笔难以稳定触发第二次命中。
- 污渍数量过多时，橡皮擦会被迫将技能充能用于清理，而非输出。

### 掉落建议

- 墨滴
- 潮霉纸团
- 墨晕残膜
- 吸墨纤维

### 一句话定位

> 墨晕团不是来打死玩家的，而是来一点点吃掉战场地板的。

## 2. 潮纸软泥

**类别：** 纸张系
**定位：** 吸收弹丸 / 减速黏附
**常见生态：** 载体地板
**威胁等级：** 中

### 损耗来源

潮纸软泥来源于纸张吸水后纤维结构崩坏、粘连和软化的现象。大量受潮纸页在亚空间中压缩成一团湿重的纸浆生物。

### 外观表现

它像一团由湿纸、残页和纸浆组成的灰白软泥，体内夹杂着模糊的横线、表格和文字。移动时会发出湿纸被揉搓的声音。

### 行为与攻击

潮纸软泥移动缓慢，但身体具有吸附能力。

主要能力包括：

- 吞入第一枚命中的小型弹丸。
- 被弹丸命中后短暂膨胀。
- 向玩家喷出湿纸团，命中后降低移动速度。
- 贴近玩家后尝试包裹角色，使闪避启动变慢。
- 死亡时留下短暂的潮湿纸浆区域。

它相当于一种低速移动的弹丸缓冲墙，可以保护身后的远程敌人。

### 被武器克制

**粉笔，强克制**

粉笔第一次命中可能被潮纸软泥吸收，但会让它进入膨胀状态。第二根粉笔命中膨胀部位时，可以使内部粉笔碎裂并从体内爆炸。

**橡皮擦，中度克制**

橡皮技能可以逐步清除潮湿纸浆区域，并对软泥表面造成连续擦除伤害。

**铅笔，较弱**

铅笔的第一发笔芯容易被湿纸纤维吸收，需要连续攻击同一位置才能穿透。

### 对武器的反制

- 吸收铅笔的第一发攻击，保护后排。
- 潮湿区域降低玩家移动速度，使铅笔更难拉开距离。
- 潮湿纸浆会降低公转橡皮擦的移动速度。
- 单独出现时不利于粉笔触发二段爆炸。

### 掉落建议

- 纸纤维
- 潮霉纸团
- 湿化纸芯
- 吸水纤维团

### 一句话定位

> 潮纸软泥是一堵会吸收子弹、还会把玩家鞋底粘住的湿纸墙。

## 3. 脆页偶

**类别：** 纸张系
**定位：** 冲锋 / 自爆
**常见生态：** 载体地板
**威胁等级：** 中

### 损耗来源

脆页偶来源于纸张长期处于低湿环境后发生的脆化、断裂和粉化。

### 外观表现

它是一只由折纸结构组成的人偶，四肢关节布满裂纹。行动过程中会不断掉落细小纸屑，冲锋前身体会向内折叠成尖锐形态。

### 行为与攻击

脆页偶会保持中距离观察玩家，随后锁定方向发动直线冲锋。

- 冲锋前有明显折叠动作。
- 撞到玩家后立即爆裂。
- 撞墙后会眩晕，并暴露纸核。
- 生命值过低时也会尝试自爆。
- 爆炸后产生数枚短距离碎纸片。

它主要考验玩家对冲锋路线和距离的判断。

### 被武器克制

**铅笔，强克制**

冲锋前的准备动作给了铅笔充足的远程点杀时间。直线冲锋也容易被铅笔穿透命中。

**粉笔，中强克制**

多只脆页偶发动冲锋时容易排成直线，可以作为粉笔的连续爆炸目标。

**橡皮擦，条件克制**

公转橡皮可以削减其生命值，主动技能也能在它撞墙眩晕后快速擦除纸核。

### 对武器的反制

- 贴身自爆会惩罚依赖近距离公转的橡皮擦。
- 突然改变冲锋方向会破坏粉笔的瞄准阵型。
- 多方向冲锋会压缩铅笔玩家的站位空间。

### 掉落建议

- 活页纸片
- 脆裂纸灰
- 断裂纤维
- 折页骨架

### 一句话定位

> 脆页偶是一张已经脆到不想活了的纸，并决定拉玩家一起碎掉。

# 三、霉菌系敌人

## 4. 黑斑菌团

**类别：** 霉菌系
**定位：** 中毒污染 / 区域扩张
**常见生态：** 载体地板、收纳地板
**威胁等级：** 中

### 损耗来源

黑斑菌团来源于纸张、墙角和布料表面形成的霉斑扩散。

### 外观表现

它像一块覆盖大量黑点的菌斑，身体中央呈暗绿色，边缘不断长出细小菌丝。静止时很容易与地面污染混在一起。

### 行为与攻击

黑斑菌团倾向于停留在房间角落或搜索点附近。

- 周期性释放孢子脉冲。
- 孢子命中后造成持续中毒。
- 周围存在污染地面时恢复少量生命。
- 长时间未被处理会分裂出小型菌斑。
- 会优先污染宝箱、文件柜和撤离装置附近区域。

### 被武器克制

**橡皮擦，强克制**

橡皮擦可以同时清理菌团本体周围的污染区域，切断它的恢复能力。

**粉笔，中强克制**

多个菌团固定在一定范围内时，粉笔爆炸能够同时命中它们，并清理刚分裂的小菌斑。

**铅笔，普通应对**

铅笔可以安全点杀菌团，但无法同步处理周围毒区。

### 对武器的反制

- 中毒区域迫使铅笔玩家频繁移动。
- 分散生长时会降低粉笔二段爆炸的收益。
- 多个菌团共同污染时，会消耗橡皮擦大量技能时间。

### 掉落建议

- 黑斑孢片
- 菌灰
- 菌丝束
- 潮霉纸团

### 一句话定位

> 黑斑菌团会把房间慢慢改造成一张不允许玩家落脚的霉菌地图。

## 5. 霉孢母体

**类别：** 霉菌系
**定位：** 精英召唤者 / 污染核心
**常见生态：** 载体地板、收纳地板
**威胁等级：** 高
**敌人等级：** 精英

### 损耗来源

霉孢母体来源于高湿、闷热和长期不通风环境中形成的大规模霉菌群落。

### 外观表现

它是一只体型巨大的孢子囊生物，底部由菌丝固定在地面，顶部不断鼓动。囊体表面能看到尚未成熟的小型霉菌轮廓。

### 行为与攻击

霉孢母体移动能力较弱，主要依靠召唤与污染控制房间。

- 周期性孵化小型孢子怪。
- 向远处喷射孢子团。
- 周围召唤物越多，母体获得的减伤越高。
- 生命值下降后会提高召唤频率。
- 濒死时释放一次大范围孢子爆发。
- 菌丝根部是可被攻击的弱点。

### 被武器克制

**粉笔，极强克制**

小型孢子怪可以作为粉笔的第一命中目标，母体则成为第二命中和爆炸中心。它的召唤行为反而主动为粉笔准备了引信。

**橡皮擦，强克制**

橡皮擦能够清理孢子污染、削弱菌丝根部，并在母体濒死爆发时擦除部分孢子弹幕。

**铅笔，中度克制**

铅笔可以穿透召唤物攻击母体弱点，但召唤物数量过多时，单线输出容易被拖慢。

### 对武器的反制

- 大量召唤物会淹没铅笔的单目标处理能力。
- 孢子分散时会让粉笔难以形成整齐直线。
- 持续污染会迫使橡皮擦优先清场，降低对母体输出。

### 掉落建议

- 孢核
- 菌丝束
- 雾化纤维团
- 异常纸核

### 一句话定位

> 霉孢母体是一座会不断印刷小怪的霉菌复印机。

# 四、墨水与橡胶系敌人

## 6. 干涸鬼

**类别：** 墨水系
**定位：** 充能削弱 / 后排干扰
**常见生态：** 记录地板
**威胁等级：** 中

### 损耗来源

干涸鬼来源于签字笔、钢笔和马克笔长期未密封后发生的失水、堵塞与墨芯干燥。

### 外观表现

它是一只细长空心的幽灵，身体像透明笔管，内部只剩零星干墨块。移动时会发出笔尖在干纸面上刮擦的刺耳声音。

### 行为与攻击

干涸鬼会主动保持与玩家的距离。

- 发射吸收技能充能的干墨针。
- 命中后降低当前武器的充能恢复速度。
- 会优先攻击正在使用绘制技能的玩家。
- 当玩家技能充能较低时，干涸鬼移动速度提高。
- 受到攻击后会短暂进入半透明状态。

### 被武器克制

**铅笔，强克制**

干涸鬼生命值不高，又习惯停留在远处，是铅笔最典型的优先点杀目标。

**橡皮擦，中度克制**

橡皮擦不依赖远程弹丸，公转攻击也不受充能削弱影响。但玩家需要冒险靠近干涸鬼。

**粉笔，较弱**

干涸鬼通常单独站在后排，周围缺乏第二个目标帮助粉笔爆炸。

### 对武器的反制

- 降低铅笔和粉笔绘制技能的充能恢复。
- 会在玩家按住右键时发起攻击，干扰橡皮技能路径控制。
- 半透明移动会使粉笔第一、第二命中难以连续衔接。

### 掉落建议

- 干墨块
- 干涸黑结
- 空壳管
- 笔芯碎段

### 一句话定位

> 干涸鬼不会直接夺走玩家的生命，它会先把武器右键榨干。

## 7. 橡屑灵

**类别：** 橡胶系
**定位：** 视野遮挡 / 粉尘干扰
**常见生态：** 辅助地板
**威胁等级：** 中

### 损耗来源

橡屑灵来源于橡皮长期磨损、硬化和掉屑形成的细小碎屑。

### 外观表现

它由大量灰白橡皮屑聚合成球状身体，表面持续抖落颗粒。受到攻击时，身体会短暂散开再重新聚合。

### 行为与攻击

橡屑灵会在玩家周围高速绕行。

- 周期性释放遮挡视野的粉尘云。
- 粉尘会降低敌人轮廓和瞄准辅助的清晰度。
- 吸收地面的粉笔灰后体型增大。
- 体型增大后生命值和接触伤害提高。
- 受到强击退后会散落，并暂时无法行动。

### 被武器克制

**橡皮擦，强克制**

主动橡皮可以擦除粉尘云。技能橡皮持续接触时，会阻止橡屑灵重新聚合。

**铅笔，中度克制**

在粉尘尚未展开前，铅笔可以快速点杀橡屑灵。

**粉笔，较弱**

粉笔爆炸产生的粉笔灰可能被橡屑灵吸收，使其获得强化。

### 对武器的反制

- 遮挡视野，直接影响铅笔精准瞄准。
- 吸收粉笔灰，削弱粉笔的后续爆炸循环。
- 多只橡屑灵分散绕行时，会让粉笔难以形成直线。
- 被动状态的公转橡皮只能造成伤害，不能清除粉尘。

### 掉落建议

- 橡屑
- 擦痕粉
- 老化胶皮
- 橡皮核心

### 一句话定位

> 橡屑灵会把干净的战斗画面变成一块刚擦完、但没吹掉橡皮屑的作业纸。

# 五、塑料与金属系敌人

## 8. 脆壳夹虫

**类别：** 塑料系
**定位：** 正面反弹 / 防御单位
**常见生态：** 尺规地板
**威胁等级：** 中至高

### 损耗来源

脆壳夹虫来源于塑料外壳在紫外线、低温或长期使用后产生的脆化和裂纹。

### 外观表现

它是一只拥有透明半圆形甲壳的昆虫，壳体内部布满白色裂纹。正面甲壳会反射光线，腹部则相对柔软。

### 行为与攻击

脆壳夹虫会主动将甲壳朝向玩家。

- 正面壳体可以偏转小型直线弹丸。
- 反弹前壳体会发出明显亮光。
- 受到连续攻击后裂纹增加。
- 冲锋撞墙后会短暂翻倒，暴露腹部。
- 从侧面和背面攻击时不能反弹。
- 壳体破裂后会进入高速逃跑状态。

### 被武器克制

**铅笔，条件克制**

铅笔从正面攻击会被偏转，但可以利用高精度攻击侧面、背部或翻倒后的腹部。

**粉笔，条件克制**

未裂开的粉笔会被正面甲壳弹开。已经完成第一次穿透的裂纹粉笔撞击甲壳时，可以直接在壳体附近爆炸。

**橡皮擦，较弱**

硬质塑料无法被快速擦除，公转攻击只能逐渐磨损裂纹。

### 对武器的反制

- 强烈反制铅笔的正面直线攻击。
- 可以将粉笔弹回，打乱二段爆炸路线。
- 对橡皮擦接触伤害具有较高稳定性。
- 迫使玩家改变站位，而不能原地自动输出。

### 掉落建议

- 脆壳片
- 裂透明片
- 透明覆膜晶片
- 硬化塑料核

### 一句话定位

> 脆壳夹虫是三把初始武器共同的期中考试，答案不是换更高伤害，而是绕到侧面。

------

## 9. 锈夹虫

**类别：** 金属系
**定位：** 快速追踪 / 连续穿刺
**常见生态：** 尺规地板、收纳地板
**威胁等级：** 中

### 损耗来源

锈夹虫来源于回形针、订书钉和长尾夹受潮后产生的锈蚀与弹性失效。

### 外观表现

它像一只由弯曲回形针组成的小虫，身体表面覆盖橙红锈迹，前端拥有两根订针状口器。

### 行为与攻击

锈夹虫会快速接近玩家，并在近距离进行连续穿刺。

- 移动速度较快。
- 接近后发动二至三次短突刺。
- 攻击结束后有短暂硬直。
- 多只锈夹虫会从不同方向包围玩家。
- 受到击退后会短暂蜷缩。

### 被武器克制

**橡皮擦，中强克制**

公转橡皮能够阻挡其贴近路线，并在连续接触中造成稳定伤害。

**粉笔，中度克制**

成群追击时，锈夹虫容易在狭窄路径排成一列，成为良好的二段爆炸目标。

**铅笔，中度克制**

铅笔可以在它们靠近前击杀，但面对多方向包围时效率下降。

### 对武器的反制

- 多方向贴身会破坏铅笔的单线射击节奏。
- 快速横向移动可能躲开粉笔的二次命中。
- 连续穿刺会打断玩家控制小橡皮的过程。

### 掉落建议

- 细金属片
- 锈蚀粉
- 锈针
- 长尾夹弹片

### 一句话定位

> 锈夹虫是最基础的金属近战单位，小而快，专门趁玩家画技能时扎手。

## 10. 腐蚀骑士

**类别：** 金属系
**定位：** 装甲精英 / 正面压制
**常见生态：** 尺规地板、收纳地板
**威胁等级：** 高
**敌人等级：** 精英

### 损耗来源

腐蚀骑士来源于订书机、金属夹具和陈旧工具长期氧化后形成的大块锈蚀结构。

### 外观表现

它是一具由订书机外壳、金属尺和长尾夹组成的重甲骑士。左臂是一面生锈夹板盾牌，右臂则是一根巨大订针长矛。

### 行为与攻击

腐蚀骑士会正面推进，主动保护身后的敌人。

- 盾牌可以偏转正面小型弹丸。
- 长矛攻击拥有较长前摇和较大范围。
- 冲锋结束后背部锈核会短暂暴露。
- 会在地面留下锈蚀区域。
- 锈蚀区域降低橡皮擦公转速度。
- 生命值降低后会舍弃盾牌，进入高速攻击状态。

### 被武器克制

**铅笔，条件强克制**

铅笔可以在腐蚀骑士攻击后的恢复阶段，精准命中背部锈核。攻击正面盾牌则效率很低。

**粉笔，条件克制**

可以让粉笔先穿透腐蚀骑士身边的小怪，再在盾牌后方或背部位置爆炸。

**橡皮擦，机制克制**

主动橡皮可以清理锈蚀地面，并逐步擦除盾牌上的松动锈层，使盾牌短暂失效。

### 对武器的反制

- 正面盾牌压制铅笔与粉笔。
- 锈蚀区域降低橡皮公转速度。
- 单独出现时缺少粉笔的二段引爆目标。
- 长距离突刺可以跨过公转轨道直接命中玩家。

### 掉落建议

- 腐蚀结节
- 钝化刃片
- 订书机击发簧
- 几何恒定片

### 一句话定位

脱胶幽会主动寻找带有增益或标记状态的玩家与敌人。

- 可以移除铅笔制造的弱点标记。

## 12. 胶带蛇

**类别：** 胶黏剂系
**定位：** 路线封锁 / 武器束缚
**常见生态：** 辅助地板、收纳地板
**威胁等级：** 中

### 损耗来源

胶带蛇来源于透明胶卷边、缠绕、互相粘连和切口不整齐形成的废弃胶带。

### 外观表现

它是一条由半透明胶带缠绕而成的长蛇，体内可以看到被粘住的纸屑、毛发和金属碎片。头部是一枚锯齿状胶带切割器。

### 行为与攻击

胶带蛇会围绕场地移动并铺设胶带线。

- 在两个墙面或障碍物之间拉出胶带。
- 玩家穿过胶带时会短暂减速。
- 胶带可以捕获低速弹丸。
- 靠近玩家后会尝试缠住公转武器。
- 受到爆炸时身体可能断成两段，但不会分裂成新敌人。
- 头部切割器是弱点。

### 被武器克制

**粉笔，强克制**

粉笔爆炸可以同时破坏多段胶带，并对长条形身体造成较高收益。

**铅笔，中强克制**

铅笔能够精准命中蛇头切割器，也可以穿透多段弯曲身体。

**橡皮擦，状态依赖**

主动橡皮可以擦除胶层，但被动公转橡皮可能被胶带缠住并暂时降低公转速度。

### 对武器的反制

- 可以捕获速度较慢或已经穿透一次的粉笔。
- 缠住公转橡皮，削弱其被动防御。
- 胶带封路会限制铅笔玩家的后撤位置。
- 多段透明胶在复杂背景中不容易被发现。

### 掉落建议

- 透明胶卷边
- 胶粒
- 拉伸胶膜
- 双面胶残片

### 一句话定位

> 胶带蛇不急着咬玩家，它更喜欢先把整个房间粘成一张蜘蛛网。

## 13. 渗胶蛞蝓

**类别：** 胶黏剂系
**定位：** 地形污染精英 / 移动压制
**常见生态：** 辅助地板
**威胁等级：** 高
**敌人等级：** 精英

### 损耗来源

渗胶蛞蝓来源于胶体在高温下软化、渗漏和外溢形成的大面积黏连污染。

### 外观表现

它是一只大型黄透明蛞蝓，身体内部漂浮着气泡、标签碎片和失去粘性的胶块。身后留下闪亮的胶质路径。

### 行为与攻击

渗胶蛞蝓会围绕房间缓慢爬行，逐渐铺满地面。

- 身后持续留下减速胶路。
- 向玩家喷射扇形胶滴。
- 胶滴命中后提高闪避消耗。
- 可以吞噬附近的小型胶黏敌人恢复生命。
- 受到近距离伤害时释放黏性冲击。
- 生命值较低后会加速爬行。

### 被武器克制

**橡皮擦，极强克制**

主动橡皮可以直接清理胶路，技能小橡皮能够沿胶路追踪本体，形成完整的净化和输出循环。

**铅笔，中度克制**

蛞蝓体型大、移动慢，容易被铅笔持续命中。但铅笔无法清理地面胶路。

**粉笔，较弱**

渗胶蛞蝓通常独立行动，缺少第二目标。胶路还会降低玩家调整粉笔射击角度的能力。

### 对武器的反制

- 胶路限制铅笔玩家的拉扯空间。
- 让玩家难以寻找粉笔二段爆炸角度。
- 被动橡皮接触胶路时公转速度降低。
- 喷胶可能打断技能橡皮的路径操作。

### 掉落建议

- 渗胶囊
- 软化脂
- 黏连脂块
- 自愈胶质块

### 一句话定位

> 渗胶蛞蝓的血条并不是唯一问题，它身后的整张黄色地毯才是。

# 七、木质系敌人

## 14. 断芯虫

**类别：** 木质与石墨系

**常见生态：** 记录地板、收纳地板
**威胁等级：** 低

### 损耗来源

断芯虫来源于铅笔内部笔芯断裂后形成的多节碎芯。

### 外观表现

裂木狼来源于木杆铅笔、木质尺具和旧货架因干燥产生的纵向开裂。

**定位：** 灼热黏地 / 软质护壳
**常见生态：** 画笔地板
**威胁等级：** 中

### 损耗来源

蜡泪怪来源于蜡笔在高温环境下软化、融化和相互粘连。

### 外观表现

它像一团不断滴落的彩色蜡液，身体表面覆盖半凝固蜡壳。不同个体可能拥有红、蓝、黄等主色。

### 行为与攻击

**铅笔，中强克制**

铅笔可以从远处持续攻击，避免进入热蜡区域。蜡壳冷却后也容易被尖锐笔芯击穿。

- 热蜡黏住公转橡皮，显著降低橡皮效率。

### 掉落建议

- 蜡料滴块
- 蜡泪核
- 软蜡膜
- 色层颗粒

### 一句话定位

# 九、布料系敌人

## 18. 霉布蝠

**类别：** 布料系 / 霉菌系
**定位：** 飞行污染 / 孢子投放
**常见生态：** 收纳地板、载体地板
**威胁等级：** 中

### 损耗来源

霉布蝠来源于笔袋、布制收纳盒和帆布用品受潮发霉。

### 外观表现

它拥有由破旧布片组成的翅膀，身体缝线已经松脱，飞行时会抖落灰绿色布孢粉。

### 行为与攻击

霉布蝠会在房间上方循环飞行。

- 周期性向地面投放孢子团。
- 孢子团落地后形成污染区。
- 会主动飞向未被污染的区域。
- 受到攻击后可能释放一小团孢子烟雾。
- 多只霉布蝠会分散投放，逐步覆盖房间。

当多只霉布蝠经过同一航线时，粉笔能够连续命中并在空中爆炸。但正常分散状态下效率一般。

**橡皮擦，环境克制**

橡皮擦难以攻击飞行本体，但可以快速清除它们投放的孢子区域。

### 对武器的反制

- 飞行状态反制橡皮擦直接攻击。
- 分散飞行降低粉笔爆炸收益。
- 地面孢子区限制铅笔站位。
- 持续投放会让橡皮擦陷入“只清地、不打怪”的防守循环。

### 掉落建议

- 霉布片
- 布孢粉
- 雾化纤维团
- 毛笔纤维

### 一句话定位

> 霉布蝠负责在天上飞，玩家的橡皮擦负责在地上追着它擦作业。

# 十、环境系敌人

## 19. 紫外眼

**类别：** 环境系
**定位：** 定点远程炮台 / 激光压制
**常见生态：** 记录地板、画笔地板
**威胁等级：** 中至高

### 损耗来源

紫外眼来源于日照、展示灯和紫外线长期照射造成的纸张黄化、塑料老化和颜料褪色。

### 外观表现

它是一只漂浮或固定在墙面的发光眼球，瞳孔周围拥有类似灯管的环形结构。锁定玩家时，瞳孔会逐渐缩小。

### 行为与攻击

紫外眼通常固定在房间边缘。

- 使用预警线锁定玩家。
- 短暂蓄力后发射持续激光。
- 激光会在地面留下短暂灼痕。
- 玩家靠近后会触发环形闪光。
- 受到攻击后会短暂闭眼。
- 多只紫外眼可以交叉封锁路线。

### 被武器克制

**铅笔，极强克制**

固定位置、远程威胁、明显蓄力，使紫外眼成为铅笔最典型的优先目标。

**粉笔，较弱**

紫外眼通常单独位于墙边，缺少第二个敌人帮助粉笔完成爆炸。

**橡皮擦，环境应对**

橡皮擦可以清理激光留下的灼痕，但无法擦除持续激光本体。

### 对武器的反制

- 激光本体不能被橡皮擦直接删除。
- 单独驻守使粉笔难以触发二段爆炸。
- 持续光束迫使玩家中断小橡皮操作。
- 交叉激光会压缩铅笔的安全射击位置。

### 掉落建议

- 光灼晶
- 白膜瞳片
- 透明覆膜晶片
- 褪颜粉

### 一句话定位

> 紫外眼是一座需要铅笔立即处理的墙面监控摄像头，否则整间房都会变成激光尺规题。

## 20. 灰尘侯

**类别：** 环境系
**定位：** 召唤精英 / 低能见度控制
**常见生态：** 收纳地板、辅助地板
**威胁等级：** 高
**敌人等级：** 精英

### 损耗来源

灰尘侯来源于货架、仓库、文件柜和文具包装长期积尘形成的环境污染。

### 外观表现

它是一只体型巨大的尘团怪，身体外形像披着破旧斗篷的贵族，头顶戴着由废纸标签形成的歪斜礼帽。

### 行为与攻击

灰尘侯不会直接高速追击玩家，而是逐渐改变整个房间的能见度。

- 持续生成灰尘雾。
- 召唤小型尘灵。
- 尘灵会围绕玩家并干扰瞄准。
- 灰尘浓度越高，灰尘侯获得的减伤越高。
- 会向玩家释放扇形尘暴。
- 生命值降低后，召唤频率与雾气浓度提高。
- 清除足够灰尘后会暴露核心。

### 被武器克制

**粉笔，极强克制**

大量尘灵会主动为粉笔提供连续命中目标，爆炸能够同时清理召唤物并伤害灰尘侯。

**橡皮擦，强克制**

主动橡皮能够清理灰尘雾，降低灰尘侯减伤，并让其核心重新显形。

**铅笔，较弱**

低能见度与大量尘灵会干扰精准瞄准，铅笔很难稳定攻击核心。

### 对武器的反制

- 强烈反制铅笔的精准点杀。
- 尘灵从多个方向包围，会让铅笔输出被分散。
- 灰尘与粉笔灰视觉接近，可能干扰粉笔爆炸区域判断。
- 若橡皮擦不主动持有，它无法清除灰尘雾。

### 掉落建议

- 灰团核
- 尘羽
- 净化滤膜
- 雾化纤维团

### 一句话定位

> 灰尘侯会先删除玩家的视野，再让自己变成一团看不清血条的高贵灰尘。

# 十二、敌人反制武器总览

## 主要反制铅笔的敌人

- 脆壳夹虫：正面反弹笔芯。
- 腐蚀骑士：盾牌阻挡直线攻击。
- 灰尘侯：低能见度和召唤物干扰瞄准。
- 裂木狼：高速横移和侧向扑击。
- 墨晕团：污染地面，迫使玩家不断移动。

## 主要反制粉笔的敌人

- 褪颜鸟：分散飞行并移除板书标记。
- 裂木狼：高速横移破坏敌人阵型。
- 干涸鬼：通常单独出现，且削减技能充能。
- 紫外眼：固定孤立，没有第二碰撞目标。
- 橡屑灵：吸收粉笔灰并获得强化。

## 主要反制橡皮擦的敌人

- 褪颜鸟：飞行，难以被公转橡皮命中。
- 紫外眼：持续激光不可擦除。
- 脆壳夹虫：硬质外壳抵抗接触擦除。
- 蜡泪怪：热蜡黏住橡皮并降低公转速度。
- 胶带蛇：缠住被动公转的橡皮擦。
- 裂木狼：扑击可以跨过公转轨道。

# 十三、组合设计原则

敌人组合应形成战术问题，而不是简单堆叠血量。

## 推荐组合一：墨迹封锁

```text
墨晕团 + 紫外眼
```

墨晕团限制玩家站位，紫外眼用激光封锁剩余安全路线。

推荐切换：

```text
铅笔点杀紫外眼
→ 橡皮擦清除墨迹
```

## 推荐组合二：霉菌工厂

```text
霉孢母体 + 黑斑菌团
```

母体召唤敌人，菌团扩散毒区。

推荐切换：

```text
粉笔利用召唤物引爆母体
→ 橡皮擦清理孢子污染
```

## 推荐组合三：尺规装甲线

```text
脆壳夹虫 + 腐蚀骑士
```

夹虫反弹弹丸，骑士正面推进。

推荐操作：

```text
诱导冲锋撞墙
→ 绕到侧面
→ 铅笔攻击弱点
```

## 推荐组合四：胶质走廊

```text
胶带蛇 + 渗胶蛞蝓
```

胶带蛇封锁路线，蛞蝓铺设减速胶路。

推荐切换：

```text
粉笔炸断胶带
→ 橡皮擦沿道路清除胶质
```

## 推荐组合五：空地双重污染

```text
霉布蝠 + 墨晕团
```

霉布蝠从空中投放孢子，墨晕团在地面扩散污渍。

推荐切换：

```text
铅笔击落霉布蝠
→ 橡皮擦清理地面
```

# 十四、一句话总结

首批二十种敌人共同构成三种战场问题：

- 铅笔负责解决“哪个目标最危险”。
- 粉笔负责解决“敌人如何排列和聚集”。
- 橡皮擦负责解决“战场环境已经脏成什么样”。

玩家不应该因为看到某个属性图标而换武器，而应该因为读懂了敌人的行为，主动切换到更合适的文具。
