# 0. 文档说明

## 0.1 文档目的

本说明书用于统一《魔法文具工坊》重构后的核心方向、玩法循环、系统边界、内容结构、技术方案与开发顺序。

v3.0 版本不再将“类吸血鬼幸存者”作为主要类型，而是重新定位为：

> **以六类地板生态和文具武器切换为核心的地牢搜打撤 Roguelite。**

旧版本中可继续保留的内容包括：

- 文具魔法题材
- 温姬妤、郑倪英等角色
- 磁核市、蔚兰群岛与亚空间世界观
- 六大文具武器类别
- 文具损耗具象化敌人
- 材料、物资与污染资源
- 工坊后勤与研究系统
- 侵蚀值与多结局结构
- 暑假 56 天主线时间框架

旧版本中需要删除或重写的内容包括：

- 连续 20 分钟类幸存者怪潮
- 经验球驱动的高频升级三选一
- 多武器自动叠加式攻击
- 时间满额自动撤离
- 固定百分比资源带出
- 六类锚点提供次日数值 Buff 的旧设计

## 0.2 使用原则

- 所有系统优先服务于核心循环。
- 所有随机生成内容必须建立在可控的手工模板上。
- 永久成长以解锁新玩法为主，纯数值提升为辅。
- 武器克制以行为机制和环境适应为主，不采用硬性免疫。
- 内容设计优先保证“小而完整”，避免单人开发规模失控。
- 未确定内容统一标记为：`[待定]`
- 暂不开发内容统一标记为：`[以后再做]`

# 1. 项目概览

## 1.1 一句话概述

《魔法文具工坊》是一款以六类地板生态与文具武器切换为核心的 2D 俯视角地牢搜打撤 Roguelite。玩家携带一把文具武器进入每日翻新的亚空间，在最多四层地牢中探索房间、寻找另外两把武器、构筑局内 Build、管理背包负重，并在继续深入与安全撤离之间作出选择。

## 1.2 高概念描述

玩家扮演文具工坊店长温姬妤，进入由文具损耗、污染与异常现象构成的亚空间地牢。不同地板生态会生成对应敌群、环境机关与物资池，玩家需要不断切换文具武器应对局势。每层地牢都隐藏着一间撤离房，找到后可以选择带着当前物资离开，或继续进入更深层的高风险区域。

## 1.4 第一卖点

> **六类地板生态会改变敌群、地形和战斗问题，玩家必须通过切换不同文具武器寻找更高效的解决方案。**

## 1.5 第二卖点

> **具体文具拥有不同的鼠标绘制技能，玩家画出的笔迹、图形或擦除轨迹会直接转化为攻击和地牢交互。**

## 1.6 第三卖点

> **每层都能撤离，但撤离房位置未知；背包越重，撤离防守时间越长，玩家必须在贪婪与安全之间反复判断。**

# 2. 世界观与叙事背景

## 2.1 世界结构

### 磁核市

磁核市是高密度、高现代化的都市核心区，具有上海式的大型都会气质。城市强调效率、就业、消费与快速流动，是温姬妤大学生活和就业压力的来源。

### 蔚兰群岛

蔚兰群岛由多个岛屿与港口聚落组成，具有崇明岛、舟山群岛式的边缘与缓冲气质。这里节奏较慢，但也存在产业衰退、人口流失与旧设施老化等问题。

### 海域

磁核市与蔚兰群岛相隔约 16 公里。海域不仅承担地理连接，也被视为现实与亚空间之间的过渡带，是异常雾气、失真航线与亚空间入口出现的重要原因。

### 亚空间

亚空间是现实中文具损耗、污染、遗失与情绪压力共同沉积形成的异常领域。它并非完全独立的异世界，而是现实空间被重新“书写”后的投影。

亚空间会每日翻新：

- 房间连接改变
- 地板生态改变
- 敌人群落改变
- 撤离房位置改变
- 物资与任务目标改变
- 侵蚀程度随剧情上升

## 2.2 核心设定关键词

| 术语 | 含义 |
|---|---|
| 亚空间 | 现实文具损耗与异常现象具象化形成的地牢区域 |
| 侵蚀值 | 衡量亚空间对现实工坊和世界影响程度的全局指标 |
| 灵墨币 | 单次探索中使用的局内货币 |
| 墨尘 | 成功撤离或死亡保底获得的局外成长资源 |
| 文具武器 | 将现实文具功能转译为攻击、控制和环境交互的装备 |
| 地板生态 | 六类文具主题在地牢中的环境、敌群与规则集合 |
| 撤离房 | 每层固定生成但位置未知的离开或深入节点 |
| 图纸 | 成功带回新武器后解锁的局外制造记录 |

## 2.3 故事开端

温姬妤从磁核市人文医学大学毕业后，没有顺利找到实习与工作。她暂时回到南蔚兰群岛，在青梅竹马郑倪英的帮助下接手一家文具工坊。

工坊表面上经营普通文具，实际承担着监测与处理亚空间异常的职责。温姬妤最初只把这段经历视为就业前的过渡，但随着侵蚀不断加剧，她逐渐发现：

- 文具店并非偶然成为入口
- 郑倪英早已研究亚空间多年
- 工坊的历史与蔚兰群岛的异常有关
- 亚空间正在从“损耗投影”转变为能主动影响现实的存在

## 2.4 核心主题

- 面对不确定性，而不是持续逃避
- 资源有限时如何承担责任
- 现实损耗如何转化为心理与空间异常
- 经营一家小工坊与守护两个世界之间的反差
- 记录、修正、整理和重新书写生活

# 4. 核心玩法循环

## 4.1 单日循环

```text
日期推进
→ 工坊简报与局外整备
→ 选择一把初始武器和消耗品
→ 查看有限地牢情报
→ 进入亚空间
→ 探索房间并完成目标
→ 收集灵墨币、武器与物资
→ 在安全房构筑 Build
→ 找到撤离房
→ 选择撤离或继续深入
→ 撤离结算 / 死亡结算
→ 更新墨尘、侵蚀值、剧情与日期
```

## 4.2 单层循环

```text
进入楼层
→ 识别主地板与次地板
→ 探索未知房间
→ 处理少量驻守敌人
→ 完成房间主要目标
→ 获取奖励和路线信息
→ 寻找撤离房
→ 选择撤离或打开下层通道
```

## 4.3 单次探索结构

- 每次探索最多 4 层
- 每层固定生成 1 间撤离房
- 撤离房开局已存在，但位置未知
- 玩家必须完成一定数量的有效房间后，才能在撤离房启动撤离
- 找到撤离房后，可以：
  - 启动撤离
  - 放弃撤离并打开下一层入口
- 死亡或撤离都会推进一天

# 5. 56 天章节结构

## 5.1 时间结构

主线保留暑假 56 天，调整为：

> **8 章 × 每章 7 天**

每一天代表一次主要探索机会。

## 5.2 每章基本节奏

| 天数 | 建议内容 |
|---|---|
| 第 1 天 | 新章节介绍、新地板生态或新机制教学 |
| 第 2～3 天 | 常规探索与资源积累 |
| 第 4 天 | 角色事件或特殊委托 |
| 第 5 天 | 复合地板与高价值任务 |
| 第 6 天 | 高风险任务或精英挑战 |
| 第 7 天 | 章节 Boss、剧情节点或大型异常 |

## 5.3 八章方向建议

| 章节 | 主要内容 |
|---|---|
| 第一章 | 工坊接手、记录地板与基础撤离教学 |
| 第二章 | 载体地板、纸张异常与隐藏出口 |
| 第三章 | 辅助地板、污染清理与负重压力 |
| 第四章 | 尺规地板、机关和路线构造 |
| 第五章 | 画笔地板、颜色污染与复合状态 |
| 第六章 | 收纳地板、封存物资与异常档案 |
| 第七章 | 多地板复合、侵蚀扩张与高风险任务 |
| 第八章 | 最终亚空间、结局条件与工坊命运 |

## 5.4 日期与失败

### 成功撤离

- 带回背包中的物资
- 获得墨尘
- 新武器首次带回时解锁图纸
- 根据任务结果降低或控制侵蚀值
- 推进一天

### 死亡

- 丢失本次探索中获得的物资
- 局前携带的永久武器保留
- 获得少量保底墨尘
- 侵蚀值增加
- 推进一天

### Bad End 条件

侵蚀值过高会逐步关闭正常结局条件，并可能触发 Bad End。

侵蚀值可受到以下内容影响：

- 死亡
- 主线任务失败
- 放弃关键救援
- 携带污染物撤离后未处理
- 特定剧情选择
- 连续多日未完成最低探索目标

# 6. 地牢系统

## 6.1 生成原则

采用：

> **手工房间模板 + 标签约束 + 程序化连接**

不采用完全随机生成房间内部。

每个房间模板至少记录：

- 房间尺寸
- 出入口方向
- 地板类型
- 房间目标
- 敌人生成点
- 搜索点
- 隐藏出口位置
- 可用机关
- 奖励等级
- 是否允许生成撤离房
- 是否允许生成安全房

## 6.2 楼层组成

每层拥有：

- 1 个主地板类型
- 1～2 个次地板类型
- 少量异常或混合房
- 1 间撤离房
- 0～1 间安全房
- 0～1 间商人房
- 若干目标房和普通探索房

## 6.3 房间类型

| 房间类型 | 主要功能 |
|---|---|
| 普通探索房 | 少量驻守敌人、基础物资与路线选择 |
| 战斗目标房 | 限时清理敌人并获得额外奖励 |
| 污染清理房 | 处理地板污染源 |
| 限时收集房 | 在限定时间内收集指定物资 |
| 护送房 | 保护并移动某个目标 |
| 隐藏出口房 | 观察环境并找到秘密通路 |
| 安全房 | 消费灵墨币、调整 Build、恢复与整理背包 |
| 商人房 | 购买稀有改造、遗物或消耗品 |
| 工坊台房 | 改造文具武器规则 |
| 特殊房 | 随机事件、交易、风险奖励 |
| 撤离房 | 撤离或进入下一层 |
| Boss 房 | 章节或高风险任务的主要挑战 |

## 6.4 房间完成判定

只有完成房间主要目标，才计入有效探索房间数。

| 目标类型 | 完成条件 |
|---|---|
| 清理全部敌人 | 击败目标敌人 |
| 清理地板污染 | 净化所有污染核心或达到净化比例 |
| 限时收集 | 收集指定数量的物资 |
| 护送物体 | 护送目标到达终点 |
| 隐藏出口 | 找到并激活隐藏出口 |

## 6.5 限时奖励

战斗目标房通常提供 60～90 秒的额外奖励时间。

在时间内完成：

- 获得额外灵墨币
- 提高稀有物资掉落
- 降低少量侵蚀
- 提供安全房或撤离房方向提示

超时后：

- 房间仍然可以完成
- 失去额外奖励
- 不直接判定失败

# 7. 六类地板生态

## 7.1 设计原则

六类地板不是单纯贴图差异，而是同时决定：

- 环境机关
- 敌人行为
- 物资池
- 房间目标
- 推荐武器
- 搜索风险
- 特殊事件

每种地板拥有：

- 2 个优势武器类别
- 2 个普通武器类别
- 2 个相对吃力类别

“相对吃力”只表示效率较低，不代表伤害无效。

## 7.2 记录地板

### 环境特征

- 墨迹轨迹
- 书写符号
- 远程射线
- 被记录后重复触发的机关
- 会扩散或重现的攻击路径

### 常见敌人

- 墨晕团
- 干涸鬼
- 紫外眼
- 书写残影类敌人

### 常见物资

- 墨滴
- 干墨块
- 笔芯碎段
- 精密笔尖
- 星墨结晶

### 适应关系建议

- 优势：辅助类、收纳类
- 普通：记录类、载体类
- 吃力：尺规类、部分画笔类

## 7.3 载体地板

### 环境特征

- 折叠纸墙
- 纸片风
- 可破坏纸桥
- 覆盖与包裹机关
- 受潮和脆裂区域

### 常见敌人

- 脆页偶
- 霉孢母体
- 黑斑菌团
- 纸质召唤物

### 常见物资

- 纸纤维
- 活页纸片
- 折页骨架
- 异常纸核

## 7.4 辅助地板

### 环境特征

- 胶面减速区
- 修正液覆盖区
- 可擦除陷阱
- 黏附门与封锁带
- 污染净化装置

### 常见敌人

- 橡屑灵
- 脱胶幽
- 渗胶蛞蝓
- 污染附着型敌人

### 常见物资

- 橡屑
- 胶粒
- 透明胶卷边
- 橡皮核心
- 自愈胶质块

## 7.5 尺规地板

### 环境特征

- 几何轨道
- 反射墙
- 测量机关
- 角度门
- 直线切割陷阱

### 常见敌人

- 锈夹虫
- 脆壳夹虫
- 金属与塑料装甲敌人
- 直线冲锋敌人

# 8. 战斗系统

## 8.1 操作定位

战斗采用“B 偏 A”模式：

- 普通攻击自动释放
- 玩家决定瞄准方向
- 玩家主要负责移动
- 玩家决定武器切换
- 玩家释放鼠标绘制技能
- 玩家使用闪避和消耗品
- 玩家在战斗中拾取物资

## 8.2 推荐操作

| 操作 | 默认按键 |
|---|---|
| 移动 | WASD |
| 武器切换 | 1 / 2 / 3 或鼠标滚轮 |
| 绘制技能 | 鼠标右键长按 |
| 快速技能 / 特殊交互 | 鼠标左键或 Q `[待原型验证]` |
| 闪避 | Space |
| 交互 / 拾取 | E |
| 使用消耗品 | 鼠标左键点击下方快捷槽 |
| 背包 | Tab |
| 地图 | M |

## 8.3 三武器结构

- 局前携带 1 把永久武器
- 局内寻找另外 2 把武器
- 最多装备 3 把武器
- 不限制武器类别重复
- 重复类别会产生明显功能短板
- 武器可以现场替换
- 备用武器可以装入背包，但重量较高
- 首次成功带回某把武器后，解锁对应图纸

## 8.4 自动普通攻击

普通攻击：

- 不消耗资源
- 根据当前武器自动攻击
- 可采用最近目标、鼠标方向或锁定目标逻辑
- 负责维持基础战斗节奏
- 不应比绘制技能更有表现力

## 8.5 绘制技能

### 基本流程

```text
充能完成
→ 玩家按住技能键
→ 游戏进入时间减速
→ 玩家可低速移动
→ 鼠标绘制轨迹或图形
→ 松开技能键
→ 轨迹实体化并结算效果
```

### 核心规则

- 绘制技能消耗充能
- 普通攻击、击杀、完美闪避等行为可以恢复充能
- 绘制期间世界减速而非完全暂停
- 玩家在绘制期间可以低速移动
- 每把武器拥有不同的轨迹长度、宽度、采样方式和特殊规则

### 推荐基础参数

```csharp
MaxStrokeLength
StrokeWidth
DrawDuration
SlowMotionScale
ChargeCost
ChargeRecovery
PointInterval
BaseDamage
EffectDuration
SpreadRadius
Penetration
```

# 9. 文具武器系统

## 9.1 六大类别

| 类别 | 核心交互语法 | 战斗定位 |
|---|---|---|
| 记录类 | 绘制笔画、标记路径 | 精准输出、持续书写、弱点打击 |
| 载体类 | 展开、折叠、包裹 | 防御、召唤、铺场 |
| 辅助类 | 擦除、黏附、修正 | 清弹幕、净化、控制 |
| 尺规类 | 确定端点、角度和图形 | 几何攻击、切割、定点爆发 |
| 画笔类 | 涂抹、着色、混合 | 范围覆盖、状态叠加 |
| 收纳装订类 | 框选、连接、封存 | 聚怪、束缚、战利品保护 |

## 9.2 首发记录类示例

### 铅笔

- 定位：稳定基础武器
- 普通攻击：自动发射笔芯或直线刺击
- 绘制技能：长距离细笔画
- 特点：墨迹长度长、路径稳定、机制简单
- 优势：处理成排敌人、远距离目标
- 改造示例：
  - 直线度越高，伤害越高
  - 穿透敌人后留下石墨碎片
  - 终点生成弱点标记
  - 笔画撞墙后分裂

### 圆珠笔

- 定位：持续书写型
- 普通攻击：连续低伤弹丸
- 绘制技能：中长曲线墨迹
- 特点：敌人接触笔迹时持续受伤
- 改造示例：
  - 同一敌人多次接触时叠加书写标记
  - 笔迹交叉点产生额外伤害
  - 曲线越长，持续时间越久
  - 标记敌人死亡后向附近传播

### 钢笔

- 定位：短距离范围伤害
- 普通攻击：高伤墨滴
- 绘制技能：短笔迹并向两侧晕染
- 特点：墨迹长度短，但会形成范围伤害区域
- 改造示例：
  - 终点生成墨池
  - 墨迹沿墙扩散
  - 两段晕染重叠时爆墨
  - 被晕染敌人死亡后留下污染区

## 9.3 其他类别示例

### 橡皮

- 鼠标擦过区域可清除弹幕、污染和敌方效果
- 对墨迹或纸张类敌人有机制优势

### 直尺

- 确定起点和终点，生成笔直切割线
- 适合处理队列、装甲与狭窄通道

### 圆规

- 选择圆心和半径，生成环形攻击
- 可用于包围敌人或建立短暂安全区

### 马克笔

- 以较宽轨迹涂抹地面
- 留下持续状态区域

### 毛笔

- 鼠标速度决定笔迹粗细
- 快速挥动形成长而细的攻击
- 缓慢拖动形成浓重范围效果

### 文件夹

- 鼠标拖出矩形区域
- 框选小型敌人、投射物或掉落物

# 10. 局内 Build 系统

## 10.1 设计目标

局内 Build 以武器规则改造为主，数值成长为辅，少量通用遗物作为补充。

## 10.2 灵墨币

灵墨币是单次探索内使用的货币。

### 获取方式

- 完成房间目标
- 限时奖励
- 击败精英
- 搜索特殊容器
- 出售局内物品
- 完成随机事件

### 消费位置

灵墨币不能随时在菜单中消费，只能在：

- 安全房
- 商人房
- 工坊台
- 特殊房间

### 消费内容

- 武器规则改造
- 重新随机改造选项
- 购买通用遗物
- 恢复生命与技能充能
- 购买消耗品
- 缩短撤离时间
- 解锁临时地图情报

### 结算规则

- 灵墨币仅在当前探索中有效
- 撤离或死亡后清空
- 不直接转化为局外墨尘

## 10.3 武器改造类型

| 类型 | 示例 |
|---|---|
| 轨迹变化 | 分叉、反射、回环、交叉爆炸 |
| 状态变化 | 燃烧、减速、易伤、束缚 |
| 条件触发 | 完美闪避后强化下一次笔画 |
| 环境联动 | 墨迹沿墙扩散、污染区被擦除后爆炸 |
| 多武器联动 | 钢笔晕染被橡皮擦除时产生冲击波 |
| 数值强化 | 伤害、范围、持续时间、充能速度 |

## 10.4 通用遗物

通用遗物数量应控制，避免喧宾夺主。

示例：

- 轻量背带：负重对移速影响降低
- 自动归档夹：同类材料堆叠效率提高
- 备用墨囊：进入新楼层时恢复部分技能充能
- 模糊地图：显示撤离房可能所在区域
- 污染标签：携带污染物时伤害增加，但侵蚀增长加快

# 11. 搜索、背包与负重

## 11.1 搜索形式

玩家可在战斗期间搜索和拾取物资。

搜索点包括：

- 文件柜
- 抽屉
- 文具箱
- 污染纸堆
- 展示柜
- 废弃工坊台
- 锁定档案箱

部分搜索需要读条，读条期间：

- 玩家可以取消
- 玩家移动速度降低
- 自动攻击仍可继续
- 受到攻击可能中断或降低进度

## 11.2 背包双限制

背包同时具有：

1. 格子限制  
2. 重量限制  

### 格子限制

决定：

- 物品尺寸
- 排列方式
- 备用武器占用
- 高价值物资与普通材料的空间竞争

### 重量限制

主要影响：

- 移动速度
- 闪避消耗
- 撤离速度

不额外惩罚攻击力、绘制精度和受击伤害，避免系统过度复杂。

## 11.3 负重阶段建议

| 负重比例 | 状态 | 效果 |
|---|---|---|
| 0%～40% | 轻装 | 无惩罚 |
| 40%～70% | 正常 | 闪避消耗轻微增加 |
| 70%～90% | 超重 | 移速下降、闪避消耗明显增加 |
| 90%～100% | 严重超重 | 撤离速度显著降低 |
| 超过 100% | 无法拾取 | 必须丢弃或替换物品 |

## 11.4 物资分类

| 类别 | 主要用途 |
|---|---|
| 基础材料 | 基础制作、修复与订单 |
| 专项零件 | 对应武器升级与图纸研究 |
| 稀有素材 | 高级设施、传奇武器与主线任务 |
| 污染物资 | 高风险高收益资源 |
| 订单物品 | 支线、声望与剧情推进 |
| 新武器 | 装备、替换或带回解锁图纸 |

# 12. 撤离系统

## 12.1 撤离房

每层固定生成 1 间撤离房：

- 开局已经存在
- 玩家不知道其位置
- 必须完成最低数量的有效房间后才能启动
- 找到后可以撤离或进入下一层

## 12.2 撤离流程

```text
满足最低探索要求
→ 找到撤离房
→ 选择启动撤离
→ 根据负重生成撤离防守时间
→ 出现小型怪潮
→ 防守成功
→ 带出背包物资
```

## 12.3 负重与撤离时间

背包越重：

- 撤离装置启动越慢
- 防守时间越长
- 可能生成更多干扰敌人

## 12.4 快速撤离

玩家可以支付物资缩短撤离时间。

可支付内容：

- 灵墨币
- 普通材料
- 污染物资
- 对应撤离装置要求的专项零件
- 高价值物品

快速撤离的核心体验是：

> 玩家可能为了保住背包中最重要的战利品，主动牺牲一部分已经获得的资源。

## 12.5 深入下一层

玩家找到撤离房后，可以放弃当前撤离并打开下层通道。

进入下一层后：

- 敌人强度上升
- 稀有物资概率上升
- 主地板与次地板组合更复杂
- 污染房比例增加
- 撤离风险增加

# 13. 敌人系统

## 13.1 核心原则

敌人来自现实中文具与工坊环境中的损耗、污染、老化和异常状态。

敌人不通过高额伤害减免强迫玩家换武器，而是通过行为机制制造不同问题。

## 13.2 行为类型

| 行为 | 作用 |
|---|---|
| 追踪 | 迫使玩家移动 |
| 冲锋 | 需要控制或障碍应对 |
| 远程压制 | 需要精准武器优先处理 |
| 区域污染 | 需要辅助类武器净化 |
| 召唤 | 需要范围或收纳类处理 |
| 装甲 | 适合尺规、晕染或特殊弱点攻击 |
| 飞行 | 适合记录类远程攻击 |
| 分裂 | 适合范围覆盖或封存 |
| 偷取物资 | 迫使玩家保护掉落物 |
| 干扰绘制 | 增加技能释放压力 |

## 13.3 首发敌人建议

| 敌人 | 作用 |
|---|---|
| 墨晕团 | 留下地面污染 |
| 脆页偶 | 冲锋并自爆 |
| 断芯虫 | 基础近战追踪 |
| 紫外眼 | 定点远程射线 |
| 橡屑灵 | 产生遮挡视野的粉尘 |
| 脱胶幽 | 干扰玩家增益 |
| 褪颜鸟 | 飞行并削弱颜色效果 |
| 霉孢母体 | 精英召唤者 |

## 13.4 怪潮使用原则

怪潮只主要存在于：

- 特殊战斗房
- 护送房
- 高价值资源房
- Boss 房
- 撤离房

普通房间仅有少量驻守敌人，不形成持续刷怪。

# 15. 侵蚀值与结局

## 15.1 侵蚀值作用

侵蚀值是主线压力系统。

随着侵蚀上升：

- 异常房比例提高
- 复合地板出现
- 敌人行为变得更复杂
- 工坊损耗事件增加
- 部分 NPC 状态变化
- 正常结局条件逐渐关闭
- 最终可能触发 Bad End

## 15.2 降低侵蚀的方式

- 成功完成主线任务
- 击败章节 Boss
- 净化污染核心
- 完成高风险救援
- 使用工坊设施处理污染物
- 做出特定剧情选择

## 15.3 结局结构建议

| 结局 | 条件方向 |
|---|---|
| Good End | 侵蚀受控、关键任务完成、角色关系稳定 |
| Normal End | 完成主线但部分区域或关系受损 |
| Bad End | 侵蚀值过高或关键任务连续失败 |
| Hidden End | 完成特殊研究、发现工坊与亚空间真相 |

## 18.2 绘制技能音效

# 22. 核心风险与对策

| 风险 | 原因 | 对策 |
|---|---|---|
| 绘制技能不好操作 | 战斗中绘制容易手忙脚乱 | 时间减速、轨迹简化、长度限制 |
| 六类地板工作量过大 | 每类都需要敌人、素材和机关 | 原型先做 2 类，验证后扩展 |
| 武器切换没有意义 | 自动攻击可能掩盖机制差异 | 通过敌人行为和地板机关制造功能需求 |
| 搜打撤压力不足 | 永久武器不丢失 | 使用物资损失、日期推进和侵蚀值增加制造压力 |
| 背包管理过于繁琐 | 格子与重量双限制 | 控制物资类型，提供快速比较与自动堆叠 |
| 四层流程过长 | 单局时间可能失控 | 每层可撤离，普通任务可限制最大层数 |
| 56 天内容量过大 | 需要大量事件与关卡 | 采用章节模板、重复任务变体与关键日重点演出 |
| Godot C# 架构耦合 | 系统多、状态复杂 | Resource 数据驱动、EventBus 解耦、模块化场景 |

# 23. 原型验收问题

新版原型完成后，需要验证：

1. 玩家是否会主动根据敌人行为切换武器？
2. 两种地板是否真的带来不同的探索与战斗问题？
3. 绘制技能是否比普通攻击更有表现力和策略性？
4. 自动攻击是否让玩家有足够精力处理移动、切换与绘制？
5. 玩家是否会因重量变化而主动丢弃物品？
6. 找到撤离房时，玩家是否会认真考虑撤离或深入？
7. 灵墨币改造是否能明显改变武器玩法？
8. 死亡推进日期与侵蚀增长是否有压力，但不会过度劝退？
9. 一层地牢是否能在 10～15 分钟内完成？
10. 截图或短视频能否在数秒内表现“六类地板 + 文具切换 + 鼠标绘制”？

# 24. 快速精简版

## 一句话概述

携带一把文具武器进入每日翻新的亚空间地牢，在六类地板生态中寻找另外两把武器，通过切换武器、鼠标绘制技能和局内 Build 解决敌人与环境问题，并在最多四层地牢中决定撤离或继续深入。

## 核心卖点

- 六类地板生态与武器切换
- 鼠标绘制文具技能
- 三武器局内构筑
- 格子背包与负重撤离
- 56 天章节主线与侵蚀结局

## 核心循环

```text
工坊整备
→ 携带一把武器进入地牢
→ 探索房间
→ 寻找另外两把武器
→ 使用灵墨币改造 Build
→ 找到撤离房
→ 撤离或深入
→ 带回物资与墨尘
→ 日期和侵蚀值推进
```

## 原型范围

- Godot 4.x + C#
- 2 种地板
- 3 把武器
- 3 种敌人
- 3 种房间目标
- 1 层地牢
- 6～8 个房间
- 一套完整撤离流程
