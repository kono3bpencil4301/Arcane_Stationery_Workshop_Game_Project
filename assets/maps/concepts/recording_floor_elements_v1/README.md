# 记录地板独立元素 v1

本目录包含 8 张与记录地板母版风格一致的独立透明 PNG。所有文件均为 `1254 × 1254` RGBA 图像，已通过透明通道、边缘留白、品红残色、触边与假棋盘格严格验证。

## 地面贴花

- `01_ink_trail_decal.png`：分叉墨迹轨迹，可旋转、缩放或组合成重复触发路径。
- `02_ink_puddle.png`：墨池与飞溅，可作为污染区、伤害区或装饰。
- `06_abstract_glyph_cluster.png`：不可读的抽象书写痕迹，适合墙边和地面叙事。

## 机关与碰撞元素

- `03_replay_trigger_plate.png`：重复触发板，可绑定路径重放或机关复现。
- `04_ray_emitter.png`：射线发射器本体，不包含射线特效。
- `05_archive_slab.png`：档案矮台，可作为掩体、碰撞物或搜索点底座。

## 物资拾取物

- `07_dried_ink_chunk.png`：干墨块。
- `08_precision_pen_nib.png`：精密笔尖。

## 使用说明

- 当前文件是高分辨率概念资产；导入 Godot 前建议按项目的实际像素密度进行最近邻缩放。
- 地面贴花通常不启用碰撞；触发板和射线发射器使用独立交互区域；档案矮台使用矩形碰撞。
- 保持 `Filter = Nearest`，避免像素边缘变糊。
