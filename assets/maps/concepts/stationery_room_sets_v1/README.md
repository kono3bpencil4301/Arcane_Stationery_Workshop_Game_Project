# ASW 六类地板房间概念草案 v1

本目录根据 [`ASW_项目设计说明书_v3.0`](../../../../docs/ASW_项目设计说明书_v3.0.md) 与 `map_record_part_01.png` 的视觉语言生成，用于房间模板、机关语法和路线结构的前期讨论。

这些图片是概念草稿，不是可直接导入 TileMap 的最终瓦片资源。进入制作阶段时，应按 `RoomTemplateResource` 的字段重新搭建出入口、目标点、生成点、搜索点、隐藏出口和机关。

## 六套房间母版

六张母版统一为 `1254 × 1254` PNG，画布与房间构图比例均为 `1:1`。

1. `01_recording_floor_room.png`：记录地板；墨迹轨迹、抽象书写痕迹、重复触发机关、射线路径。
2. `02_carrier_floor_room.png`：载体地板；折叠纸墙、纸桥、包裹门、受潮与脆裂区域。
3. `03_auxiliary_floor_room.png`：辅助地板；胶带门、胶黄减速区、修正液覆盖、擦除与净化装置。
4. `04_ruler_compass_floor_room.png`：尺规地板；几何轨道、反射墙、切割线、角度门、圆规轴心。
5. `05_brush_color_floor_room.png`：画笔地板；青/品红/琥珀状态区、颜料扩散、混色节点、笔刷门。
6. `06_storage_binding_floor_room.png`：收纳与装订地板；文件柜通道、文件夹门、拉链封锁、归档锁与封存库。

## 4×6 地图草图总表

文件：`07_map_draft_4x6.png`

行定义（从上到下）：

1. 记录地板
2. 载体地板
3. 辅助地板
4. 尺规地板
5. 画笔地板
6. 收纳与装订地板

列定义（从左到右）：

1. 普通探索房：开放环路、基础搜索点、2～4 个候选出口。
2. 目标房：中心目标区或战斗场、2～3 个候选出口。
3. 生态机关 / 隐藏出口房：侧向机关、绕行路线、2 个候选出口。
4. 特殊 / 安全 / 撤离房：明确中心装置、1～2 个候选出口。

## 统一视觉约束

- 2D 俯视角、16-bit 像素风、硬边瓦片结构。
- 冷灰地面、深褐黑墙顶、灰白轮廓、板岩蓝磨损痕迹。
- 薄荷青三角形出口作为跨生态统一识别符。
- 房间内部必须保留清晰可行走留白、碰撞轮廓和可读路线。
- 不在地图位图中放置 UI、角色、敌人或需要精确阅读的文字。
